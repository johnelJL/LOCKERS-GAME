# Lockers Game

A static, self-contained simulation of the classic lockers puzzle. Upload the directory to any static hosting provider (or open `index.html` locally) to explore how student passes toggle lockers and why only perfect squares stay open.

## Getting started

No build steps required:

1. Download or clone this repository.
2. Upload the entire folder to your hosting service (or open `index.html` locally in a browser).
3. Visit `index.html` to access the landing page and interactive simulator.

## Features

- Responsive landing page designed for static hosting
- Interactive controls to choose the number of lockers and students
- Instant visualization of locker states with perfect-square highlighting
- Summary of open vs. closed lockers and their factorization

## Development

The project is plain HTML, CSS, and JavaScript. Modify the files directly and refresh your browser to see updates.
